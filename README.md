# Testing & Subsea — Tally Book MVP

Bu ilk web MVP'sidir.

## Çalıştırma
`index.html` dosyasını modern bir tarayıcıda açabilirsiniz.

## İçerik
- Splash screen / Testing & Subsea
- Ana sayfa
- Yeni test oluşturma
- Gerçek zamanlı elapsed timer
- Her dakika otomatik tally satırı
- Actual pressure girişi
- Allowed pressure drop kontrolü
- Otomatik OK / FAIL
- Not alanı
- Test geçmişi
- Test detay ekranı
- Yazdır / PDF (tarayıcının Print > Save as PDF özelliği)
- localStorage ile tarayıcı içi otomatik kayıt

## Sonraki üretim sürümü
- Merkezi database
- Kullanıcı girişi ve yetkilendirme
- Sunucu tarafı veri saklama
- PDF rapor şablonu
- İmza / witness
- Audit trail
- Offline/PWA desteği
- Çoklu test tipleri ve şirket standartlarına göre kriterler
